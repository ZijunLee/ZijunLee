## Hi, I'm Zijun Li

Applied mathematician and ML scientist (PhD, Humboldt-Universität zu Berlin), based in Berlin.

I work on **model selection and optimization for ML-driven decisions**, and on **careful evaluation**,
from multi-objective hyperparameter tuning to RL post-training and LLM agents that verify their own evidence.

**Selected work**
- [agentic-research-assistant](https://github.com/ZijunLee/agentic-research-assistant): LLM research agent with hybrid retrieval, PDF page inspection and an evidence verifier
- [Critic-Free-Reinforcement-Learning-Post-Training](https://github.com/ZijunLee/Critic-Free-Reinforcement-Learning-Post-Training): controlled comparison of six critic-free reinforcement learning (RL) methods (REINFORCE, ReMax, RLOO, GRPO, …) for LLM post-training under a fixed GPU budget, 3 seeds each
- [Algorithm-Switching-for-Multiobjective-Predictions](https://github.com/ZijunLee/Algorithm-Switching-for-Multiobjective-Predictions): Bayesian optimization + direct search for multi-objective model selection (LION 2024)
- [MBO_Networks](https://github.com/ZijunLee/MBO_Networks): scalable graph clustering with MBO schemes (Eur. J. Appl. Math.)

**Tools:** Python · PyTorch · scikit-learn · XGBoost · pandas
